# lms-ux-demo

LMS 도우미 앱의 화면 시안입니다. 프런트엔드만 있고 백엔드는 없습니다. 과목, 교수, 과제, 공지, 강의, 파일은 모두 지어낸 데이터입니다.

배포 주소: https://leetae9yu.github.io/lms-ux-demo/

## 목표

웬만한 일은 클릭 1~2번이나 문장 한 줄로 끝나야 합니다. 앱은 학교 LMS 화면으로 가는 링크까지만 맡고, 과제 제출과 글쓰기는 학교 화면에서 합니다. 그래서 이 앱에는 제출 버튼과 글쓰기 버튼이 없습니다.

## 화면

| 화면 | 주소 | 하는 일 |
| --- | --- | --- |
| 오늘 할 일 | `#/today` | 마감 임박 과제, 안 본 녹화강의, 새 공지, 새 강의자료를 한 화면에 모읍니다. 각 줄의 버튼 하나로 과제 열기, 강의 보기, 공지 읽기, 자료 받기를 합니다. |
| 문장 명령창 | 모든 화면 위쪽 | 문장을 입력하면 결과 카드로 답합니다. `⌘K`(Windows는 `Ctrl K`)나 `/`로 바로 입력합니다. |
| 과목 | `#/course/ds` 등 | 과목 하나의 과제, 녹화강의, 강의자료, 공지를 보여 줍니다. 자료 전체 받기 버튼이 있습니다. |
| 과목 목록 | `#/courses` | 휴대폰 화면에서 과목을 고르는 목록입니다. 데스크톱에서는 사이드바가 이 일을 합니다. |
| 일정 | `#/schedule` | 한 주의 과제 마감과 강의 출석 인정 기한을 요일별로 보여 줍니다. |
| 설정 | `#/settings` | 테마, 학교 계정, 요약용 API 키, 저장 폴더, 알림을 설정합니다. 입력값은 저장하지 않습니다. |

## 주요 작업의 클릭 수

클릭 수는 앱을 연 상태(오늘 할 일 화면)에서 셉니다. 문장 명령은 명령창을 누르는 클릭 1번 또는 단축키 0번에 문장 입력과 Enter를 더한 수입니다.

| 작업 | 버튼으로 | 문장으로 |
| --- | --- | --- |
| 마감 임박 과제 페이지 열기 | 1 (오늘 화면의 「과제 열기」) | - |
| 안 본 녹화강의 열기 | 1 (「강의 보기」) | - |
| 새 공지 읽기 | 1 (「읽기」, 같은 자리에서 펼침) | - |
| 새 강의자료 하나 받기 | 1 (「받기」) | - |
| 새 강의자료 모두 받기 | 1 (「모두 받기」) | 「새 자료 다 받아줘」 |
| 한 과목 자료 전체 받기 | 2 (사이드바 과목 → 「자료 N개 모두 받기」) | 「자료구조 자료 다 받아줘」 |
| 이번 주 마감 확인 | 1 (「이번 주 마감 뭐 있어」 문장 칩) 또는 1 (사이드바 「일정」) | 「이번 주 마감 뭐 있어」 |
| 안 본 강의 개수 확인 | 0 (오늘 화면의 「안 본 강의」 숫자) | 「안 본 강의 몇 개야」 |
| 새 공지 요약 | 1 (「공지 요약해줘」 문장 칩) | 「공지 요약해줘」 |
| 과목 화면 열기 | 1 (사이드바 과목) | 「운영체제 열어줘」 |
| 다음 주 일정 보기 | 2 (「일정」 → 다음 주 화살표) | 「다음 주 마감」 |
| 다크 모드로 바꾸기 | 2 (「설정」 → 「어둡게」) | 「다크 모드로 바꿔줘」 |

휴대폰 화면에서는 사이드바 대신 하단 탭을 씁니다. 과목 화면은 「과목」 탭 → 과목 이름으로 2번입니다.

## 문장 명령이 알아듣는 말

실제 AI를 부르지 않습니다. `src/commands.ts`의 규칙이 낱말을 찾아 결과 카드를 고릅니다.

| 낱말 | 결과 |
| --- | --- |
| 받아, 다운, 내려받 (+ 과목 이름, 「새」) | 자료 받기를 바로 시작하고 진행 상황을 오른쪽 아래에 보여 줍니다. |
| 강의, 녹화, 인강 | 안 본 강의 목록과 출석 인정 기한 |
| 공지, 알림 | 새 공지 한 줄 요약 |
| 마감, 과제, 할 일 (+ 오늘, 내일, 다음 주) | 기간 안의 마감 목록 |
| 일정, 설정, 과목 이름 | 해당 화면으로 이동 |
| 다크, 어둡게, 밝게 | 테마 변경 |

과목 이름은 줄임말도 받습니다. 예: 자구, 선대, 운체, 경원, 대글.

## 실행

```bash
bun install
bun run dev      # 개발 서버
bun run build    # dist/ 생성
```

Vite, React, TypeScript를 씁니다. 색, 글자 크기, 간격, 모서리 값은 `src/styles/tokens.css` 한 파일에서 정합니다. 라이트와 다크 테마는 시스템 설정을 따르고, 설정 화면에서 바꿀 수 있습니다. `main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다.
