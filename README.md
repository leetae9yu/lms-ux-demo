# lms-ux-demo

LMS 도우미 앱의 화면 시안입니다. 프런트엔드만 있고 백엔드는 없습니다. 과목, 교수, 과제, 공지, 강의, 파일은 모두 지어낸 데이터입니다.

배포 주소: https://leetae9yu.github.io/lms-ux-demo/

## 원칙

토스는 송금에서 공인인증서와 계좌 찾기를 지우고 받는 사람과 금액만 남겼습니다. 이 앱도 학교 계정 로그인, 메뉴 찾기, 과목 고르기, 주차 찾기, 파일 찾기를 학생 머리에서 지웁니다.

1. 앱을 열면 바로 할 일이 나옵니다. 로그인 화면, 메뉴, 과목 목록이 없습니다.
2. 한 화면에는 한 가지만 둡니다. 큰 문장 하나와 큰 버튼 하나가 있고, 정보 카드 격자는 없습니다.
3. 학교 용어 대신 사람 말을 씁니다. 예: 「경제학원론 강의, 내일까지 봐야 출석 인정돼요」.
4. 일을 끝내면 「끝」 한 줄과 체크 표시가 나오고, 다음 일로 저절로 넘어갑니다.
5. 원하는 일이 화면에 없으면 한 문장으로 말합니다.

앱은 학교 화면으로 가는 링크까지만 맡습니다. 과제 제출과 글쓰기는 학교 화면에서 하므로 이 앱에는 제출 버튼과 글쓰기 버튼이 없습니다. 휴대폰 폭이 기본 화면이고, 데스크톱에서는 가운데 좁은 열로 같은 화면을 보여 줍니다.

## 화면

| 화면 | 주소 | 하는 일 |
| --- | --- | --- |
| 할 일 | `#/today` | 첫 화면입니다. 맨 앞에 「한 번에 끝내기」가 있고, 그다음부터 할 일을 하나씩 보여 줍니다. 위아래로 밀거나 화살표 버튼, 키보드 위아래 화살표로 다음 일과 이전 일을 봅니다. 다 끝내면 「오늘 할 거 다 했어요」가 나옵니다. |
| 한 문장 말하기 | 할 일 화면 아래 입력 칸, `⌘K`(Windows는 `Ctrl K`), `/` | 큰 입력 칸과 추천 문장이 나옵니다. 마감 목록, 과목 하나, 과목 목록, 공지 요약은 이 결과로만 나타납니다. |
| LMS 옆 패널 시안 | `#/panel` | 원래 구상한 형태입니다. 왼쪽은 가상 LMS 화면이고, 오른쪽 패널은 지금 보고 있는 학교 화면에서 할 일을 버튼 하나로 처리합니다. 왼쪽 탭(강의 홈, 과제 3, 공지)을 바꾸면 패널 내용도 바뀝니다. |
| 설정 | `#/settings` | 테마, 학교 계정, 요약용 API 키, 저장 폴더, 알림을 설정합니다. 입력값은 저장하지 않습니다. |

## 주요 작업의 클릭 수

클릭 수는 앱을 연 상태에서 셉니다. 문장 명령은 `⌘K` 또는 입력 칸 클릭 1번에 문장 입력과 Enter를 더한 것입니다.

| 작업 | 클릭 수 | 누르는 곳 |
| --- | --- | --- |
| 오늘 자동으로 끝낼 수 있는 일 전부 (새 자료 모두 받기, 새 공지 한 줄 요약, 마감 하루 전 알림) | 1 | 첫 화면 「한 번에 끝내기」 |
| 지금 보이는 할 일 하나 끝내기 (과제 페이지 열기, 강의 틀기, 자료 받기, 공지 확인, 알림 켜기) | 1 | 큰 버튼. 끝나면 다음 일이 저절로 나옵니다. |
| 가장 급한 과제 페이지 열기 | 2 | 「하나씩 할게요」 → 「과제 페이지 열기」 |
| 할 일 하나 미루기 | 1 | 「나중에 할게요」 또는 위로 밀기 |
| 이번 주 마감 보기 | 2 | 입력 칸 → 추천 문장 「이번 주 마감 뭐 있어」 |
| 한 과목 자료 전부 받기 | 2 | 입력 칸 → 추천 문장 「자료구조 자료 다 받아줘」 (다른 과목은 문장 입력) |
| 안 본 강의 보기 | 2 | 입력 칸 → 「안 본 강의 몇 개야」 |
| 과목 하나 열기 | 2 | 입력 칸 → 「운영체제 열어줘」 |
| 학교 화면 옆 패널에서 그 화면의 일 하나 끝내기 (자료 받기, 강의 틀기, 알림 켜기, 공지 요약) | 1 | 패널의 파란 버튼 |
| 다크 모드로 바꾸기 | 2 | 설정 → 「어둡게」 |

## 한 문장 말하기가 알아듣는 말

실제 AI를 부르지 않습니다. `src/commands.ts`의 규칙이 낱말을 찾아 결과 화면을 고릅니다.

| 낱말 | 결과 |
| --- | --- |
| 받아, 다운, 내려받 (+ 과목 이름, 「새」) | 자료 받기를 바로 시작하고 진행 상황을 보여 줍니다. |
| 마감, 과제, 할 일, 일정 (+ 오늘, 내일, 다음 주) | 날짜별 마감 타임라인과 「가장 급한 과제 열기」, 「알림 받기」 버튼 |
| 강의, 녹화, 인강 | 안 본 강의 목록과 「가장 급한 강의 틀기」 버튼 |
| 공지, 알림 | 새 공지 한 줄 요약과 「다 읽었어요」 버튼 |
| 과목 이름 | 그 과목의 할 일과 자료, 「자료 모두 받기」 버튼 |
| 과목, 수업 | 과목 목록 |
| 다크, 어둡게, 밝게, 설정, 패널 | 테마 변경 또는 해당 화면 |

과목 이름은 줄임말도 받습니다. 예: 자구, 선대, 운체, 경원, 대글.

## 실행

```bash
bun install
bun run dev      # 개발 서버
bun run build    # dist/ 생성
```

Vite, React, TypeScript를 씁니다. 색, 글자 크기, 간격, 모서리 값은 `src/styles/tokens.css` 한 파일에서 정합니다. 라이트와 다크 테마는 시스템 설정을 따르고, 설정 화면에서 바꿀 수 있습니다. `main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다.
